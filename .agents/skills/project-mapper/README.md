# 🤖 Agentes IA

Un repositorio dedicado al desarrollo, orquestación y experimentación con **Agentes de Inteligencia Artificial**.

---

## 🚀 Descripción General

Este proyecto proporciona un entorno estructurado para diseñar, probar e integrar agentes autónomos y asistentes inteligentes. Incluye herramientas de mapeo de proyectos.

---

## ✨ Características Principales

- 🧠 **Orquestación de Agentes**: Flujos de trabajo automatizados guiados por Inteligencia Artificial.
- 🗺️ **Project Mapper**: Skill integrada para mapear, filtrar y comprimir el contexto del proyecto optimizando el uso de tokens.
- 🛠️ **Modularidad y Extensibilidad**: Arquitectura diseñada para añadir nuevas skills, reglas y plugins fácilmente.

- **Python**: `3.9` o superior.
- **Node.js**: `18.x` o superior (si se ejecutan agencias/herramientas basadas en JS/TS).
- **Git**

---

## ⚙️ Instalación y Configuración

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/NicolasGirard20/Agentes_IA.git
   cd Agentes_IA
   ```

2. **Crear y activar un entorno virtual** (opcional pero recomendado):
   ```bash
   python -m venv venv
   # En Windows:
   .\venv\Scripts\activate
   # En Linux/macOS:
   source venv/bin/activate
   ```

3. **Instalar dependencias**:
   ```bash
   pip install -r requirements.txt
   ```
